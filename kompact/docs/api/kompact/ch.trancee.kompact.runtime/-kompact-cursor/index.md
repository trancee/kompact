# KompactCursor

[common]\
class [KompactCursor](index.md)(buffer: [ByteArray](https://kotlinlang.org/api/core/kotlin-stdlib/kotlin/-byte-array/index.html))

Reusable bounded cursor over a caller-owned buffer.

The cursor retains the buffer and bit bounds supplied by the caller. Reset validates the complete region before replacing its current binding. Failures are reported through primitive status and offset fields. This mutable cursor is not thread-safe; use separate cursors for simultaneously active regions.
